# Blend Digital — versão do Floot

Cópia dos 184 arquivos do projeto Floot e das cinco imagens públicas, recuperada em 5 de outubro de 2026. Os arquivos originais foram preservados; os arquivos de configuração e main.tsx foram adicionados para execução com Vite fora do Floot.

## Executar

Nesta pasta: `npm install --legacy-peer-deps`, depois `npm run dev`.
Para gerar a versão de produção: `npm run build`.

O conteúdo atual está no código. O conector Floot confirmou que o projeto não tem banco de dados. Nenhuma credencial ou dado privado de banco foi exportado.

As imagens estão em `public/_cdn/static`, mantendo as URLs usadas no código. As fontes usam Google Fonts e precisam de conexão. A hospedagem deve servir index.html também nas rotas da aplicação, incluindo /blend-news.

Os arquivos *.example.tsx contêm exemplos próprios do editor Floot e não fazem parte do aplicativo publicado. Esta é uma cópia dos arquivos acessíveis pelo conector, com configuração independente adicionada, e não o ZIP oficial Get Code. Não inclui o ambiente interno, histórico de conversas, histórico de versões, nem aplicativos móveis do Floot.

Para continuar no Codex, trabalhe nesta pasta `floot` e preserve o conteúdo e identidade visual. O restante do repositório mantém a versão anterior.
